## Strengths

- 마을이 한눈에 남아시아로 읽힌다. 박공 초가·둥근 원뿔 초가, 석회칠 흙벽 + 붉은 밑단, 야자, 사원 시카라, 가트, 소달구지, 끈 침상, 항아리, 혹소·물소. `dev_overview`·`estate_wide` 가 특히 좋다.
- 사원은 일반형이라 특정 건물을 베끼지 않았다 (휜 시카라, 층 띠, 아말라카, 칼라샤, 기둥 주랑과 계단 지붕).
- 잉글랜드 비회귀를 코드 수준에서 지켰다. 직접 확인: 10 시드의 `planAll`(집·소품·나무·땅 조각)과 `planPeople` 가 base 와 JSON 으로 동일. 요리법을 인자로 받아도 난수 차례가 그대로다. 잉글랜드 회귀 그림 2장도 이전과 같은 장면.
- 남아시아 가지가 한 군데로 모인 구조: `RECIPES`(고정 자리·간격·예약 영역), `KIT_SETS`(glb 이름·크기 표), `paletteOf`. 잉글랜드 분기는 옛 경로를 그대로 탄다.
- 생 사이 전환이 깨끗하다. 매 생 새 장면을 짓고 앞 장면을 `dispose` 한다. 나무 세트 캐시 키가 땅 × 세트라 서로 섞이지 않는다. 지오메트리는 `userData.shared` 로 공유 표시, 못 읽은 glb 는 캐시에서 지워 다음 생에 다시 시도한다.
- 사람 glb 가 변형 이름·뼈·LOD·재질을 잉글랜드와 같게 맞췄고, 시험이 그 짜임을 비교한다. `realpeople.js` 를 건드리지 않고 주소만 바꿔 끼운 것이 좋다.
- 단계 B 에서 실제 플레이로 문제를 찾아 고쳤다. 읍내 집 가게 안 새까만 판, 낮은 좌판 처마가 내 사람을 덮는 문제, 쇠똥 더미가 아이를 가리는 문제.
- 새 시험이 대체로 진짜다. glb JSON 에서 예산·노드 이름·크기 표를 직접 잰다. 12 시드로 조각 이름·정한 자리·뒤뜰·머리색·대장장이 위치를 확인한다.

- 고치는 법(결정 사항): 최소 (a) README·친구 공유 글에 「세트는 중세 인도 일반형, 동남아·고대는 임시」라고 적는다. (b) 값싼 완화: `stage.variant` 가 동남아 4곳이면 `temple_small`을 `shrine_tree`만 남기고 빼고, 고대(`stage.era === 'ancient'`)면 사원 대신 신당만 둔다. `RECIPES` 에 `without: [...]` 한 줄이면 된다. (c) 제대로 하려면 작업 2·3 이후 동남아·시대 변형을 계획에 넣는다.

**I-3. 세트·나무 빌보드 GPU 자원이 한 번 만들면 영영 풀리지 않고, 세트가 늘수록 쌓인다** — `realscene.js:137-153`(`kitCache`), `:324`·`:386`·`:453-458`(`treeCaches`), `:362` 근처 `albRT`·`nrmRT`
- 무엇: 코드와 glb JSON 으로 짐작한 크기. 남아시아 나무 종 10가지(NV=10)라 빌보드 굽기 RT 가 2048×2560 반정밀 + 8비트 → 땅×세트 하나당 약 84 MB (잉글랜드 NV=7 은 약 59 MB). 남아시아가 쓰는 땅이 monsoon·dry·tropical 셋이라 이 세트만 최대 약 250 MB. 세트 glb 텍스처(WebP 51장, 1k~2k)도 캐시된 원본 안에 남아 약 250 MB 로 짐작. 둘 다 `dispose` 가 한 번도 불리지 않는다 (캐시 키는 땅 × 세트로 유한하지만 줄어들지 않는다).
- 왜 중요한가: 친구 PC(내장 그래픽)에서 여러 땅을 오가며 몇 십 생 하면 GPU 메모리가 쌓여 장면 못 짓기·컨텍스트 소실이 날 수 있다. 작업 2·3 이 세트 셋을 더 얹으면 곱절로 는다. (실측은 못 함)
- 고치는 법: `setLife` 에서 세트가 바뀔 때 직전 세트를 뺀 나머지의 `kitCache`·`treeCaches` 를 최근 2개만 남기는 LRU 로 만들고 빠지는 쪽은 `albRT.dispose()`·`nrmRT.dispose()`·텍스처 `dispose()`. 또는 굽기를 땅이 아니라 세트당 한 번만 하고 땅 색은 빌보드 유니폼 곱으로 입힌다 (수 곱절 줄어든다).

### Minor

**M-2. 그리기 횟수 +18%(전경 1508 대 1274)의 값싼 완화** — 원인 짐작과 고칠 곳

**M-3. 못 읽는 glb 가 있으면 나무 전부가 사라진다** — `realscene.js:394`
