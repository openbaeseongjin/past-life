# 한 영혼의 여정 (One Soul's Journey)

지금까지 태어난 약 1,170억 명 가운데 한 명으로 태어나 한 생을 살아 보는 웹 게임입니다. 같은 영혼이 다음 시대에 다시 태어납니다. SIM Jam 출품작이며 아직 만드는 중입니다.

- 플레이: https://openbaeseongjin.github.io/past-life/ (PC 크롬·엣지 권장, 3D라 처음 불러오기에 시간이 조금 걸립니다)
- 지원: PC 전용(1600×900 기준). 휴대폰은 지원하지 않습니다.
